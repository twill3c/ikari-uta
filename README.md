# 怒り歌(ikari-uta)

ホメロス『イーリアス』全 24 巻を、**原文の行番号を保ったまま**日本語で読む。

名は冒頭語 μῆνιν(怒り)から採った。

## 行番号を保つ理由

体裁の問題ではない。行が保たれていれば、**訳文を検査できる**ようになる。
原文と和訳が同じ行番号の上に並ぶので、訳抜け・行ズレ・表記ゆれが機械で検出できる。
読み物としての価値と、検査可能性が、同じ一つの設計判断から出ている。

## 底本の実測(2026-08-31)

### 「イーリアスは 15,693 行」は行数ではない

| 量 | 値 |
|---|---|
| 巻 | 24 |
| **実在する行** | **15,687** |
| 行番号の最大値の和 | 15,693 |
| 差 | 6 行 |

流通している 15,693 という数字は、**各巻の行番号の最大値を足したもの**だった。
差の 6 行は、校訂者(Monro & Allen)が本文から除きながら番号だけを残した行である。

| 巻 | 欠番 |
|---|---|
| 9 | 458, 459, 460, 461 |
| 11 | 543 |
| 14 | 269 |

**行番号は連番ではない。第 9 巻は 457 の次が 462 になる。**
配列の添字と行番号を同一視すると、そこから下流(訳の整列・出典行)が例外を出さずに 4 行ずれる。
正準データは行番号を明示的に保持し、添字から導出しない。

### 英訳は行単位では照合できない

Murray 英訳(`perseus-eng3`)は `<l>` 要素を持たない散文で、原文行との対応は
`<milestone unit="line">` で与えられる。実測したアンカー間隔は**中央値 5 行**
(3,082 / 3,143 件が間隔 5、最大 15)。

**英訳による照合の分解能は ±5 行の窓である。** 塊単位の脱落は捕まえられるが、
1 行のずれは捕まえられない。この限界を超える主張を英訳に負わせない。

## 進捗

| | 状態 |
|---|---|
| 第 1 巻 | 全訳(611 行) |
| 第 2 巻 | 全訳(877 行) — 軍船の一覧を含む |
| 第 3 巻 | 全訳(461 行) — 一騎打ちと城壁の場面 |
| 第 4 巻 | **全訳(544 行)** — 誓いの破棄と開戦 |
| 第 5–24 巻 | 準備中(原文・英訳は表示可能) |

訳済み **2,493 行 / 15,687 行**。

全巻の完訳には複数ループを要する。巻を足しながら育てる。

### 巻は分けて訳してよい

第 2 巻の固有名詞は行域で極端に偏る(実測 2026-08-31)。

| 行域 | 対訳表に無い新規固有名詞 |
|---|---|
| 本編 1–483 | 42 語 |
| 軍船の一覧 484–877 | **373 語** |

一覧は事実上の地名辞典で、対訳表を 6 倍にする**後戻りできない凍結**を伴う。
そこで一覧は、陣営・指揮系統の抽出と同じループで扱った —— 名前の凍結と名簿の抽出が
互いを検算し合うようにするため。一覧専用の対訳表は `data/glossary.catalogue.json`(374 語)。
検査は**統合後の表**に当たるので、分けたことで G-03 は緩んでいない。

**不完全は欠陥ではない。** 検査は「原文にない行が訳にある」ことだけを失敗にし、
どれだけ揃ったかは**測って出す**(HC-085)。

## 軍船の一覧は自分の検算を持っている

一覧は各部隊の隻数を本文に書いている。だが**機械抽出では届かない**。

| 経路 | 合計 |
|---|---|
| 原文の数詞を素朴に拾う | 1,075 |
| 英訳の「N ships」を素朴に拾う | 1,056 |
| **部隊ごとに確認して組んだ名簿** | **1,186** |

素朴な抽出が落とすのは規則の穴ではなく、対象の性質だった。

- `two and twenty ships`(22 隻)—— 複合数詞。「twenty」だけ拾って 2 隻落ちる
- `four leaders, and ten swift ships`(4 将 × 10 隻 = 40 隻)—— 掛け算が要る
- 「ships」40 件の出現のうち **10 件は部隊の隻数ではない**(総論・アキレウスの不参加の記述)

**名簿が先、合計はその検算**である。29 部隊を一件ずつ確かめて組んだ結果、
合計は 1,186 隻となり、外部権威と一致した。順序を逆にすると、
合わせるための解釈を選んでしまう。名簿は `data/roster.json`、検査は `tests/test_roster.py`。

### 同じ名前が別人を指す

一覧には同名異人・同名異地が集中する。対訳表に注記して残した。

| 表記 | 別人・別地であること |
|---|---|
| アカマース | アンテーノールの子(823)/ トレーキア勢の将(844) |
| アンティポス | コースの将(678、アカイア方)/ マイオニアの将(864、トロイア方) |
| アンピマコス | エペイオイの将(620)/ カリアの将(870) |
| エピストロポス | ポーキスの将(517)/ エウエーノスの子(692)/ ハリゾーネスの将(856) |
| エウリュピュロス | コースの王(677)/ エウアイモーンの子(736) |
| エウリュトス | オイカリエーの王(596)/ アクトールの子(621) |
| ミーレートス | クレータ島の町(647)/ 小アジアの町(868) |

`ἀργεϊφόντης` に慣例訳「アルゴス殺し」を採らないのも同じ理由である。
この Ἄργος(百眼の怪物)は都市の Ἄργος と別物で、同じカタカナに潰すと
別の指示対象が一語に重なる。

## 検査が保証すること・しないこと

**保証する。**

- **G-01** 訳に**原文に存在しない行が無い**。訳した範囲は原文の行順に沿って連続する
  (完全性は不変量ではなく被覆率として測る — HC-085)
- **G-02** 固有名詞の出現行が原文と一致する
- **G-03** 固有名詞のカタカナ表記が凍結した対訳表と一致する(表外表記ゼロ)
- **G-04** 訳文にギリシャ文字・キリル文字・ハングル・制御文字が混入しない
- **G-05** 全ページに底本の帰属・ライセンス・機械翻訳である旨を表示する

**保証しない。**

日本語訳は **Claude による機械翻訳**であり、学術的な定訳ではない。
保証するのは「落ちていない・ズレていない・表記が揺れていない」であって、**訳の正確さや文学的品質ではない**。
この区別は画面にも明示している。

## オラクルの循環を避ける

行数オラクルは、正準データを作るのと同じ経路で数えない。同じ走査で数えた値と比べても
恒等式になり、緑でも何も検査していない(HC-045)。経路を 2 本に分けている。

| 経路 | 実装 | 用途 |
|---|---|---|
| **A(DOM)** | `xml.etree.ElementTree` で木を walk | 正準データの生成 |
| **B(走査)** | 生バイト列を正規表現で線形走査 | 行数オラクルの生成 |

比べるのは**集合だけでなく出現順序列**も含める(HC-065)。さらに欠番を詰めて連番にした
**贋オラクルを照合が落とすこと**を陽性対照で確かめている。
外部権威(流通値 15,693)を第 3 の錨に置いている。

## 課金経路を持たない

- 和訳は**開発時**に生成してコミットする。ビルド工程で LLM を呼ばない
- サーバ関数ゼロ・cron ゼロ・実行時の外部通信ゼロ。純粋な静的配信
- これらは主張ではなく検査で担保する(`tests/test_shipping.py`)

## 使い方

```bash
python pipeline/fetch_perseus.py      # 底本の取得(キャッシュ優先)
python pipeline/parse_tei.py          # 経路 A → 正準データ
python pipeline/line_oracle.py        # 経路 B → 行数オラクル
python pipeline/parse_english.py      # 英訳 → 行アンカー区間
python pipeline/assemble_ja.py        # 訳文断片 → 巻別 JSON(突合つき)
python pipeline/build_site.py         # 出荷物の生成

python -m pytest -q                   # 検査
python harness/text_hygiene.py        # 字種検査
python harness/inspect_site.py        # 実ブラウザ検品(複数幅・欠番注記の対照つき)
```

## 訳を足す

1. `data/canonical/book-NN.json` から原文を読む
2. `data/ja/src/book-NN/*.tsv` に `行番号<TAB>訳文` で書く(分け方は自由)
3. `python pipeline/assemble_ja.py --book NN` — 原文と行番号が合わなければ例外で止まる
4. `python -m pytest -q` — 表外表記・字種を検査する

対訳表 `data/glossary.json` は**凍結されている**。表にない固有名詞を使うと G-03 が落ちる。
表を変えるときは専用ループを立て、既訳の全巻を洗い替える。
